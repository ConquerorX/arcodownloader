# Конфиденциальность

**Кратко: ARCOD Grab не собирает никаких данных и ничего не отправляет ни на один сервер.**
Нет ни серверной части, к которой могли бы получить доступ разработчик или третьи лица.

## Данные, которые не собираются

- Личная информация, данные учётной записи, электронная почта, IP
- История загрузок, прослушивания и поиска
- Статистика использования, отчёты о сбоях, телеметрия
- Cookie (расширение не читает и не записывает никаких cookie)

## Данные, остающиеся в браузере

Только в `localStorage` origin `player.arcod.xyz`:

| Ключ | Содержимое |
|---|---|
| `arcodgrab.cfg.v1` | Потолок качества, шаблон имени файла, режим сохранения, положение панели, Простой режим, предпочтение «сейчас играет» |
| `arcodgrab.queue.v1` | Идентификаторы и названия треков в очереди загрузки |

Эти два ключа удаляются вместе с данными сайтов браузера. При удалении расширения они тоже исчезают вместе с сохранёнными данными сайта ARCOD. На сервер они никогда не отправляются.

## Доступ к сети

Расширение обращается только к следующим адресам:

| Адрес | Назначение |
|---|---|
| `https://player.arcod.xyz/api/player/*` | Данные альбома и билет потока |
| CDN потоков ARCOD (адрес, возвращаемый билетом) | Аудиопоток |

Единственная запись `host_permissions` в `manifest.json` — `https://player.arcod.xyz/*`. Никакой другой сайт нельзя ни прочитать, ни изменить.

## Адреса потоков (ticket)

Для каждой загрузки у ARCOD запрашивается короткоживущий адрес потока. Этот адрес:

- хранится в памяти только на время загрузки,
- **не** записывается на диск, в `localStorage` или в консоль,
- освобождается по окончании загрузки.

## Разрешения

| Разрешение | Зачем |
|---|---|
| `downloads` | Передать файл менеджеру загрузок браузера, открыть его, показать папку |
| `host_permissions: player.arcod.xyz` | Разместить панель на странице и запрашивать поток от origin страницы |

Разрешения вроде `tabs`, `storage`, `webRequest`, `cookies` и `scripting` **не запрашиваются**. URL вкладки читается только при нажатии на кнопку панели инструментов, чтобы проверить адрес текущей вкладки.

## Изменения

Если эта политика изменится, будут обновлены номер версии и `CHANGELOG.md`. Поскольку весь исходный код находится в этом репозитории, любое утверждение можно проверить:

```bash
grep -rn "fetch(" *.js      # только /api/player и адрес билета
grep -rn "sendBeacon\|XMLHttpRequest" *.js
```
